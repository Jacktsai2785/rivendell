### 🟢 Strong：`wsl-terminal-setup`
- **名稱**：wsl-terminal-setup
- **目的**：一站式調校 Windows + WSL 的 Claude Code 終端機體驗：PowerShell 7 → WSL 預設路徑（`.bashrc` / wsl.conf）、Nerd Font 檢查、starship 安裝與 `starship.toml` 設定、statusline、剪貼簿／截圖貼上（`wl-clipboard` / win32yank）行為說明與修復。

- **分類**：workflow
- **理由**：8 個 session 中有 4 個在處理同一主題，且每次都是從零重新偵測環境。既有的 `vscode-wsl-port-forwarding-debug` 只涵蓋 port forwarding，不重疊。知識點（win32yank vs OSC52 剪貼簿差異、starship 設定、.bashrc 進入點）已在本次 sessions 驗證過，可直接固化。
